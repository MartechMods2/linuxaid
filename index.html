People behind the foundations

Linux & Unix legends worth learning from.

These stories are not here for hero worship. They show how useful ideas, patient maintenance and clear engineering can grow into technology used by millions of people.

About the LinuxAid founder
Kernel creator • Git creator

Linus Torvalds

Torvalds began developing the Linux kernel in 1991 and later created Git to support large-scale distributed software development. Linux grew because people could study it, improve it and collaborate around it.

Linux kernelGitOpen collaboration

Lesson to carry forward: start with a useful problem, build something real, and let collaboration make it bigger than one person.

Read the Linux Foundation profile →
Kernel maintainer • Stable releases

Greg Kroah-Hartman

Kroah-Hartman has maintained the Linux stable kernel branch and major areas including USB, driver core, tty and sysfs. His work represents the less glamorous but essential discipline of keeping Linux reliable over time.

Stable kernelDriversMaintenance

Lesson to carry forward: creating something is only the beginning. Reliability comes from reviewing, maintaining and improving it again and again.

Read the Linux Foundation profile →
Unix roots • C • Systems thinking

Ken Thompson & Dennis Ritchie

Thompson and Ritchie created Unix at Bell Labs, and Ritchie developed C into the language that made Unix portable. Linux is not Unix, but Unix ideas and interfaces heavily shaped the environment Linux later grew into.

UnixCPortable systems

Lesson to carry forward: simple, composable ideas can outlive the machines they were first built for.
