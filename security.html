LinuxAid trust centre

Security

LinuxAid is designed around safe learning, protected member data and server-side handling of sensitive service credentials.

Account safety

Use a strong unique password, verify your email when requested and sign out on shared devices. LinuxAid may automatically end an inactive session to reduce account risk.

AI and secrets

AI provider secret keys are kept on protected server-side infrastructure rather than placed in browser code. Never paste passwords, private keys or access tokens into AI prompts, community posts or messages.

Terminal safety

The browser terminal is a simulator. Dangerous command patterns are blocked, but guidance should still be reviewed before using commands on a real machine.

Reporting

If you discover a security issue, report it privately through the official LinuxAid support channel and avoid publicly exposing user data or exploit details before a fix is available.
