Privacy

Privacy should be understandable.

Last updated 17 September 2026.

What LinuxAid stores

When you create an account, Supabase Auth handles account identity and authentication. LinuxAid may store profile fields, learning progress, community posts/replies, follows, direct-message records, notifications, reactions, bookmarks and reports needed to provide the features you use.

Public versus private

Community posts and fields on a profile you mark public can be visible to other visitors or signed-in members. Direct conversations are protected by database row-level security so only conversation members can read them through the application.

Analytics

LinuxAid can use consented product analytics to understand which features work. Session replay is disabled in the current configuration and Do Not Track is respected where implemented by the analytics runtime.

AI requests

AI prompts are sent through the authenticated LinuxAid Edge Function to the configured provider. Provider API keys are server-side secrets and are not exposed to the browser. Do not paste passwords, private keys, recovery codes or other secrets into AI prompts or community content.

Local device data

Some learning progress and interface preferences can be kept in browser storage for offline or fast local use. The profile page provides export/import and local reset controls.

Security and retention

LinuxAid uses Supabase row-level security, validation and rate limiting for supported social features. No internet service can promise absolute security, so use a unique password and protect your signed-in devices.
